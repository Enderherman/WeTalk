# 版本发布管理与版本比较修复

日期：2026-10-04。

## 行为

- `saveUpdate` 和 `checkUpdate` 按 major/minor/patch 三段数字比较版本，`1.10.0` 正确高于 `1.9.9`，不再拼接数字或按字符串排序。
- 版本号最多 10 字符，更新说明最多 500 字符；外链仅允许无用户名/密码的 HTTP/HTTPS URL，最多 200 字符。
- 新增本地版本须上传非空 `.exe` 安装包（最大 500 MiB）；编辑本地草稿可保留已有安装包。
- 上传先写临时文件，传输失败不改数据库和已有包；临时文件被清理。数据库写入和后续文件保存失败使用事务回滚数据库。
- 编辑、删除、发布不存在的 ID 返回业务错误；已发布记录须先撤回才允许编辑/删除。
- 发布本地版本前检查包存在且非空；发布外链版本前校验 URL。
- 灰度 UID 规范为 `U` 加 11 位数字，去重并限制总长度；撤回/全量发布清空灰度名单。
- 更新检查仍使用登录身份，按实际可见范围挑选最高数字版本；草稿和其他用户灰度版本不可见。
- 文件保存、大小读取与下载均使用同一个规范化路径，配置目录末尾无需额外分隔符。
